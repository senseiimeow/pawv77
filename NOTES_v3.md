# PAWGRAM v3 — build notes

**See You Offline · Season 1** — a loud-but-beautiful, Gen-Z, sticker-book-to-Tokyo-arcade upgrade of the
whole site. Zero dependencies, zero backend, still a static PWA.

```
python3 tools/build_pages.py     # 5 pages  (index, gallery, pawfun, characters, chapters)
python3 tools/build_readers.py   # 7 readers (patches the originals in place)
python3 -m http.server 8000      # then open http://localhost:8000
```

Every page is a **single self-contained HTML file** (CSS + JS + fonts are inlined at build time);
artwork stays as lazy `webp` under `art/` and `pages/`.

## 1 · What is new, section by section

### Design system (`assets/css/pg.css`, `pg-home.css`, `pg-art.css`)
- Full token layer: `--c-coral #ff5f7e`, `--c-sakura #ffb7c5`, `--c-lav #b9a7ff`, `--c-mint #7ef0d0`,
  `--c-vending #ffd166`, `--c-sky #8fd0ff`, bg `#0a0710`, coral gradient `--grad`, glass `--glass`,
  three type roles (Bricolage display / Baloo sticker / Caveat hand) all self-hosted.
- Halftone + film-grain overlays, torn-paper edges, tape, polaroid/film-strip frames, glowing gradient
  borders, glassmorphism chat, katakana accents (オフラインで会おう).

### Loader + cursor + nav
- Battery loader 4% → 100% on Chapter 1 energy, paw walking the fill, rotating "loading the city" lines,
  skip button, `PG.stopLoader()` escape hatch.
- Paw cursor with a lagging trail + state labels (READ / PLAY / DRAG / heart), tap = petal burst on mobile.
- Floating glass pill navbar that hides on scroll-down, full-screen playful mobile drawer,
  a visible **Reduce motion** switch (nav bolt + footer chip), day/night, sound, install.

### The coral thread (the signature)
- `#threadsvg`: one fixed SVG path on the left of every desktop page that **draws itself as you scroll**
  and carries a paw bead at the head. It is generated by `pg-core.js` (§10) so all pages share it.
  Hidden under 900 px and with reduce-motion on — phones get section dividers instead.

### Home page (`index.html`)
Hero (parallax night-Tokyo, per-letter bounce-in title with neon flicker + mouse reaction, live phone chat
with typing dots and "read 02:48", cursor-following stickers) · pinned season storytelling with a draggable
Sept→April timeline · cast cards (3D tilt/flip, breathing + blinking idle, tap-to-talk bubbles, 183 cm vs
140 cm bar) · The Thread live-chat reveal with tap-to-reply auto-answers · chapters rail (drag + momentum,
tilt, first-page peek, per-chapter progress, "Continue reading" pill) · motif sticker board (drag, throw,
tap to reveal) · PawFun arcade teaser · gallery · character quiz with a canvas-generated share card ·
closing CTA (umbrella opens on scroll, rain → sakura, notify field).

### PawFun arcade (`pawfun.html`) — 6 cabinets
Paw Catch · Konbini Rush · The Thread Quiz · Umbrella Dash · **Frame 27** (new) · **Mochi Clicker** (new).
Cabinet chrome, neon marquee (INSERT COIN / オフラインで会おう), sticky dock with your best scores,
shared game-over sheets, scan-line glass on every screen, confetti + squash & stretch + screen shake,
scores in `localStorage` (`pf-catch`, `pf-konbini`, `pf-quiz`, `pf-dash`, `pf-frame27`, `pf-mochi`).

### Cast (`characters.html`)
Three.js-free 3D tilt cards, breathing/blinking portraits, tap-to-talk speech bubbles with alternating
lines, animated height bars and the 183 ↔ 140 cm comparison.

### Gallery (`gallery.html`) — new page
Film-strip ⇄ masonry toggle (remembered), tilt frames, **all 69 pages** lazy-loaded in batches of 12,
shared full-screen lightbox (`#lb`) with page-flip, swipe, pinch-zoom, ←/→/Esc, share.

### Readers (`readers/Chapter_1..7_Reader.html`)
Coral-thread progress bar with a paw handle, day/night reading, tap-to-hide UI ("h" too), panel entrance
fades (opacity only — never hurts readability), per-chapter scroll + progress saved, "Continue where you
left off" pill, reaction bar at the chapter end, fixed the Chapter 7 `prefetch null` 404.

### New social layer
Reaction bar (❤️ 🥹 🌸 😭 🐾) with local counts on every page + chapter ends · "Which character are you?"
quiz with a shareable canvas card · share-a-score · day/night (Tokyo 2 AM vs sakura afternoon) ·
ambient soundscape OFF by default (WebAudio synth, no files) · achievement badges with confetti toasts.

### PWA / tech
`manifest.webmanifest` + `sw.js` (`pawgram-v8`; CORE list cleaned of the dead `_src/*` entries and now
precaches the new pages) · SEO/OG/Twitter cards + paw favicon · `prefers-reduced-motion` respected
everywhere plus the manual switch · 320 px → 4K, no horizontal scroll at 320 px · keyboard focus states,
skip link, alt text.

## 3 · What still needs a backend (UI + localStorage today)

| Feature | Now | Connect later |
|---|---|---|
| Season 2 "Notify me" | Saves email to `pg-notify` | Formspree / Supabase `notify` table + email provider |
| Reaction counts | Per-device in `pg-reactions` | Supabase `reactions` (page, emoji, count) with a tiny RPC |
| Leaderboard | Local bests (`pf-*`) + "you only" board | Supabase `scores` + auth-less name field |
| Reading progress sync | `pg-progress` in `localStorage` | Supabase `progress` keyed by a local device id or magic link |
| Share cards | Canvas → download / Web Share | Same canvas → object storage for an OG image URL |
| Achievements | `pg-badges` | Supabase `badges`; keep localStorage as the offline fallback |
| Sound | Synthesised WebAudio (no files) | Optional CC0 ambient loops |
